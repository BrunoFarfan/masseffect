# Ganymede surface preparation

The checked-in Ganymede derivatives are generated by
`scripts/prepare-ganymede-surface.mjs --rebuild` from the ignored originals in
`output/surface-originals/`. To refresh the pinned source cache, run
`--download-pinned`, record the printed SHA-256 values in the script, then use
`--rebuild --offline`.

## Verified source

The source is the USGS Astrogeology [Ganymede Voyager - Galileo SSI Global
Mosaic 1km](https://astrogeology.usgs.gov/search/map/ganymede_voyager_galileo_ssi_global_mosaic_1km),
assembled from NASA Voyager and Galileo SSI imagery. The primary GeoTIFF is
`Ganymede_Voyager_GalileoSSI_global_mosaic_1km.tif`; its companion PDS/ISIS
label is retained beside it. The label states 16,539×8,270 unsigned-byte
single-band pixels, Simple Cylindrical projection, 1,000.067192 m/pixel,
planetocentric latitude, positive-west longitude in 0..360, center longitude
180°, source radius 2,632,344.9707 m, and upper-left projected origin
(-8,270,555.675418, 4,135,277.837709) m.

## Longitude normalization

The source's metadata-derived positive-west axis is reversed and its
half-raster seam is shifted before output. Runtime imagery is therefore
east-positive −180..180, planetocentric latitude, north-up, pixel-centered
equirectangular imagery. No visual rotation or eyeballed alignment is used.

## Relief policy

This is mapped imagery, not a DEM; image brightness is never used as height.
Each little-endian uint16 height sample encodes `height = -192 + sample × 0.5`
meters. The deterministic bounded field is generated from the 3D unit direction
vector, making it seamless at longitude and both poles, and is explicitly
synthetic rather than measured Ganymede topography.

## Derived levels

Preview, medium, and near outputs are 512×256, 1024×512, and 2048×1024.
Color derivatives are JPEG quality 88 with 4:4:4 chroma and have no legends,
labels, or map decorations. Output SHA-256 values and byte dimensions are
recorded in `assets/surfaces/ganymede-manifest.json`.
