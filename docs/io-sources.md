# Io surface preparation

The checked-in Io derivatives are generated by
`scripts/prepare-io-surface.mjs --rebuild` from the ignored original
`output/surface-originals/io-usgs-full.jpg`.

## Verified source

The source is the USGS Astrogeology [Io Galileo SSI false-color global
mosaic](https://astrogeology.usgs.gov/search/map/io_voyager_galileo_ssi_false_color_global_mosaic_1km),
assembled from Galileo/Voyager imaging. The page's bounded sample is the
1024×512 JPEG linked as `full.jpg` (the embedded JPEG metadata retains the
source raster dimensions 11445×5723). Its SHA-256 is:

`f7a0661d04046f10a903c2d6fe2d179f47b3d02d3d87be5e41824321a6766b6a`

USGS metadata records a spherical radius of 1,821,460 m, planetocentric
latitude, simple cylindrical projection, longitude −180..180, and positive
west longitude direction. The preparation therefore flips the raster
horizontally as a metadata-derived positive-west → east-positive conversion.
It does not rotate or align the map by visual inspection. The runtime target is
east-positive, north-up equirectangular sampling.

## Relief policy

This USGS product is imagery, not a DEM. Its false-color channels are never
used as elevation. The accompanying `.height.bin` files are an explicit,
deterministic procedural field independent of the source pixels, encoded as
little-endian unsigned 16-bit samples with `height = -64 + sample × 0.5 m`.
The range is deliberately bounded to −64..63.5 m and is labeled
`mapped-imagery-plus-explicit-procedural-height` in `io-manifest.json`; it is
not a claim about Io's measured topography. A future real DEM or shape model
must replace it as a separately attributed product.

## Derived levels

The source is only 1024 pixels wide, so the near level is intentionally not
upsampled: both medium and near remain 1024×512. Preview is 512×256. Color
derivatives are JPEG quality 88 with 4:4:4 chroma; all output SHA-256 values
are recorded in the manifest.

Mission and body orientation metadata may be cross-checked against the [NAIF
generic PCK](https://naif.jpl.nasa.gov/pub/naif/generic_kernels/pck/pck00011.tpc).
