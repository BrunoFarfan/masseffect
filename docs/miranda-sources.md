# Miranda surface sources

## Appearance

The color layer is NASA's official [Uranus–Miranda 3-D resource](https://science.nasa.gov/3d-resources/uranus-miranda/), credited to USGS/Tammy Becker and JPL/Caltech and mosaicked with Voyager imagery. The pinned 2048x1024 WebP is downloaded by `scripts/prepare-miranda-surface.mjs` and checked by SHA-256 before any derivative is made. Voyager 2 mapped only a limited portion of Miranda; unmapped regions remain source gaps or explicitly approximate appearance.

The NASA page does not publish longitude/latitude registration, control points, prime-meridian label alignment, or a verified pole orientation for this rendered texture. The runtime therefore uses an equirectangular, north-up, planetocentric lookup with east-positive longitude in `-180..180` only for addressing. Alignment is unverified and must not be treated as scientific coordinates. The [JPL map catalog](https://maps.jpl.nasa.gov/tmaps/) cautions against scientific analysis of aesthetically processed map textures.

## Height

No reliable complete global Miranda DEM is available. Medium and near levels use a restrained, seamless independent direction-vector field generated by the preparation script. This is a visual approximation, not measured Miranda topography, and does not sample the color image or infer elevation from brightness. Height files are little-endian uint16 with `radial height = -100 + sample * 0.5 m`; each manifest records decoded minimum and maximum metres and its hash.

## Rebuild

```sh
node scripts/prepare-miranda-surface.mjs --download-pinned --rebuild
```

For a fully offline reproducible rebuild, keep the downloaded file at
`output/surface-originals/miranda-voyager-texture.webp` and run:

```sh
node scripts/prepare-miranda-surface.mjs --rebuild
```

The script emits 512x256 preview color only, 1024x512 medium color plus height,
and native-capped 2048x1024 near color plus height derivatives under
`assets/surfaces/`. The source SHA-256 is
`c1827aec1d5ccd4318c9c71d24c7fbfe5d5a984e867d32744573a8d814c69085`.
