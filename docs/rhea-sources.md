# Rhea surface preparation

The checked-in Rhea derivatives are generated by
`node scripts/prepare-rhea-surface.mjs --rebuild` from the ignored originals in
`output/surface-originals/`. Refresh the pinned inputs with
`--download-pinned`; the script records and verifies both SHA-256 hashes before
it can rebuild.

## Verified official source

The source is the USGS Astrogeology [Rhea Voyager Global Mosaic
833m](https://astrogeology.usgs.gov/search/map/rhea_voyager_global_mosaic_833m),
assembled from NASA Voyager 1 imagery. The pinned GeoTIFF is
`Rhea_Voyager_mosaic_global_833m.tif` and its ISIS label is retained beside it.
The label reports 5,761×2,881 signed-16-bit single-band pixels, 833.3947 m/pixel,
sinusoidal projection, planetocentric latitude, positive-west longitude from
−180° to 180°, center longitude 0°, radius 764,000 m, and upper-left projected
origin (−2,400,593.43335, 1,200,505.06535) m. The source and label hashes are
also recorded in `assets/surfaces/rhea-manifest.json`.

## Coordinate normalization

The source projection, radius, origin, resolution, sample format, and longitude
sign were checked with the GeoTIFF and label. Each output pixel is sampled from
the source sinusoidal grid using those metadata values, converting source
positive-west longitude to runtime east-positive −180..180. Outputs are
planetocentric, north-up, pixel-centered equirectangular rasters. No visual
rotation or eyeballed alignment is used.

## Relief policy

There is no reliable complete global Rhea DEM in this preparation. Color is
never interpreted as height. Medium and near height files contain a bounded,
seamless synthetic field generated from the 3D unit direction vector, encoded
as little-endian uint16 with `height = -256 + sample × 0.5` meters. It is
explicitly procedural, not measured Rhea topography.

## Derived levels

Preview is color-only at 512×256. Medium is 1024×512 and near is 2048×1024;
both include matching height files. JPEG derivatives use quality 88 and 4:4:4
chroma. Every color and height byte length and SHA-256 is recorded in
`assets/surfaces/rhea-manifest.json`.
