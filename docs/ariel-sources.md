# Ariel surface sources

## Appearance

The color layer is NASA's official [Uranus–Ariel 3-D resource](https://science.nasa.gov/3d-resources/uranus-ariel/), identified there as a USGS mosaic using Voyager imagery and credited to USGS/Tammy Becker and JPL/Caltech. The pinned 2048x1024 WebP is downloaded by `scripts/prepare-ariel-surface.mjs` and checked by SHA-256 before any derivative is made. The related [JPL Voyager 2 color image](https://www.jpl.nasa.gov/images/pia00041-ariel-highest-resolution-color-picture/) documents the mission imagery and its southern-hemisphere coverage.

The runtime samples this 2:1 image with an equirectangular east-positive `-180..180`, planetocentric-latitude convention, but the published source metadata does not specify Ariel's prime meridian, east/west sign, or pole orientation. Alignment is therefore explicitly unverified; the script validates the pinned raster's dimensions, channels, and depth and performs no flip or rotation. Voyager coverage is uneven and concentrated in the encountered southern hemisphere. Unmapped regions are retained as source gaps/low-confidence appearance, not presented as measured global coverage.

## Height

No reliable global measured Ariel DEM is available. Medium and near levels therefore use a restrained, seamless independent direction-vector field generated by the preparation script. It is a visual approximation, not measured Ariel topography, and does not sample the color image. Height files are little-endian uint16 with `radial height = -500 + sample * 1 m`; each manifest records decoded minimum and maximum metres and its hash.

## Rebuild

```sh
node scripts/prepare-ariel-surface.mjs --download-pinned --rebuild
```

For an offline reproducible rebuild, keep the downloaded file at `output/surface-originals/ariel-voyager-texture.webp` and run:

```sh
node scripts/prepare-ariel-surface.mjs --rebuild
```

The script emits 512x256 preview color only, 1024x512 medium color plus height, and native-capped 2048x1024 near color plus height derivatives under `assets/surfaces/`. The manifest pins the source hash, every derivative hash, dimensions, encoding, scale/offset, and decoded range.
