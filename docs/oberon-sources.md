# Oberon surface sources

## Appearance

The color layer is NASA's official [Uranus–Oberon 3-D resource](https://science.nasa.gov/3d-resources/uranus-oberon/), whose texture is credited to USGS/Tammy Becker and JPL/Caltech and described as a mosaic using Voyager imagery. The pinned 2048x1024 WebP is downloaded by `scripts/prepare-oberon-surface.mjs` and checked by SHA-256 before any derivative is made. Voyager 2 mapped only about 40% of Oberon in the 1986 flyby; unmapped regions are preserved as the source's dark/blank appearance gap, not filled with invented imagery.

The source is supplied as a 2:1 equirectangular-looking texture. The pipeline samples it north-up with pixel-centered coordinates and records east-positive `-180..180` as the runtime convention, but the source metadata does not specify prime meridian or longitude direction, so alignment is unverified. It is a mapped appearance layer only; image brightness is never interpreted as elevation.

## Height

No reliable complete global Oberon DEM is available. Medium and near levels therefore use a restrained, seamless independent direction-vector field generated by the preparation script. It is a visual approximation, not measured Oberon topography, and does not sample the color image. Height files are little-endian uint16 with `radial height = -160 + sample * 0.5 m`; each manifest records decoded minimum and maximum metres and its hash. Oberon's canonical runtime reference radius is 761,400 m, kept separate from the source texture (which has no supplied physical radius).

## Rebuild

```sh
node scripts/prepare-oberon-surface.mjs --download-pinned --rebuild
```

For a fully offline reproducible rebuild, keep the downloaded file at
`output/surface-originals/oberon-voyager-texture.webp` and run:

```sh
node scripts/prepare-oberon-surface.mjs --rebuild
```

The script emits 512x256 preview color only, 1024x512 medium color plus height,
and native-capped 2048x1024 near color plus height derivatives under
`assets/surfaces/`.
