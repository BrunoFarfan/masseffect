# Titania surface sources

## Appearance

The color layer is NASA's official [Uranus–Titania 3-D resource](https://science.nasa.gov/3d-resources/uranus-titania/), whose texture is credited to USGS/Tammy Becker and JPL/Caltech and described as mosaicked with Voyager imagery. The pinned 2048x1024 WebP is downloaded by `scripts/prepare-titania-surface.mjs` and checked by SHA-256 before any derivative is made. Voyager 2 coverage is primarily Titania's southern hemisphere; the source's unmapped/black northern area is preserved and documented rather than filled with invented imagery. The related [JPL Voyager 2 image](https://www.jpl.nasa.gov/images/pia00036-titania-high-resolution-color-composite/) is retained as mission attribution and provenance.

The source texture is treated as an equirectangular, north-up, planetocentric map with east-positive longitude in `-180..180`, pixel-centered. The visualization resource does not publish a geotransform or prime-meridian convention: this lookup is an explicit approximation, not verified absolute imagery alignment. It is an appearance layer only; image brightness is never interpreted as elevation. The [JPL catalog](https://maps.jpl.nasa.gov/tmaps/) cautions against scientific analysis of these aesthetically processed textures.

## Height

No reliable complete global Titania DEM is available. Medium and near levels therefore use a restrained, seamless independent direction-vector field generated by the preparation script. It is a visual approximation, not measured Titania topography, and does not sample the color image. Height files are little-endian uint16 with `radial height = -160 + sample * 0.5 m`; each manifest records decoded minimum and maximum metres and its hash. Titania's canonical runtime reference radius is 788,900 m, kept separate from the source texture (which has no supplied physical radius).

## Rebuild

```sh
node scripts/prepare-titania-surface.mjs --download-pinned --rebuild
```

For a fully offline reproducible rebuild, keep the downloaded file at
`output/surface-originals/titania-voyager-texture.webp` and run:

```sh
node scripts/prepare-titania-surface.mjs --rebuild
```

The script emits 512x256 preview color only, 1024x512 medium color plus height,
and native-capped 2048x1024 near color plus height derivatives under
`assets/surfaces/`.
