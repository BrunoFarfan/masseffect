# Iapetus surface preparation

The checked-in derivatives are generated by
`node scripts/prepare-iapetus-surface.mjs --rebuild` from the ignored originals
in `output/surface-originals/`. Refresh the pinned inputs with
`--download-pinned`; the script records and verifies both SHA-256 hashes before
it can rebuild.

## Verified official source

The source is the USGS Astrogeology [Iapetus Cassini–Voyager Global Mosaic
803m](https://astrogeology.usgs.gov/search/map/iapetus_cassini_voyager_global_mosaic_803m),
assembled from Cassini images with Voyager images filling the poles. The pinned
GeoTIFF is `Iapetus_Cassini_Voyager_mosaic_global_783m.tif`, with its ISIS label
retained beside it. The label reports 5,760×2,880 unsigned-8-bit single-band
pixels, 802.851456 m/pixel, Simple Cylindrical projection, planetocentric
latitude, positive-west longitude from −180° to 180°, source radius 736,000 m,
and upper-left projected origin (−2,312,212.193042, 1,156,106.096521) m.
Source and label hashes are recorded in `assets/surfaces/iapetus-manifest.json`.

## Coordinate normalization

The source positive-west axis is reversed by metadata convention into runtime
east-positive −180..180. Pixel centers remain north-up and the longitude seam
wraps continuously; this is not an eyeballed visual flip. Runtime uses the
canonical physics radius 734,300 m, while the source map radius of 736,000 m is
retained separately in provenance.

## Relief policy

No reliable complete global Iapetus DEM was available for this preparation.
Color is never interpreted as height. Medium and near height files contain a
bounded, seamless synthetic field generated from a 3D unit direction vector,
encoded little-endian uint16 with `height = -256 + sample × 0.5` meters. It is
explicitly procedural, not measured Iapetus topography.

## Derived levels

Preview is color-only at 512×256. Medium is 1024×512 and near is 2048×1024;
both include matching height files. JPEG derivatives use quality 88 and 4:4:4
chroma. Every color and height byte length and SHA-256 is recorded in the
manifest. The 2048×1024 derivative remains below the 5760×2880 source native
resolution.
