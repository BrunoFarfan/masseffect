# Venus surface sources

The checked-in Venus derivatives are generated by
`scripts/prepare-venus-surface.mjs` from the version-2 USGS Astrogeology / NASA
Magellan global topography product:

- Product page: <https://astrogeology.usgs.gov/search/map/venus_magellan_global_topography_4641m>
- GeoTIFF: <https://planetarymaps.usgs.gov/mosaic/Venus_Magellan_Topography_Global_4641m_v02.tif>
- Downloaded page: `output/surface-originals/venus-source.html`
- Source raster: 8192x4096, 4641.0589 m/pixel, Simple Cylindrical centered at
  0 degrees, planetocentric latitude, north-up, east-positive x direction.
- Source SHA-256:
  `92dd2c8850b128f9dcceb400f1367e3df96229f5309840fee4275b74f192ea11`.

The source pixels are signed 16-bit elevation in metres relative to the Venus
6051800 m mean-radius datum; the source explicitly identifies `-32768` as
NoData and gives a measured range of -2951..11687 m. Runtime height files are
little-endian `uint16`: `elevation = -4000 + sample * 0.5` metres. They are
independent of color, and no image brightness is interpreted as height.

The pipeline validates GeoTIFF GeoKeys and the affine transform before reading
the raster. It writes runtime coordinates as east-positive -180..180 with
north at the first row. `preview` is color-only (512x256); measured heights
are provided at `medium` (1024x512) and `near` (2048x1024).

The separate `venus-radar.jpg` is a bounded USGS Magellan left-look SAR browse
sample. It is radar backscatter, not visible color or albedo, and must not be
used as height. Its source SHA-256 is
`5c5f4a18143bcc26fe0ab92bd9270d2549cb5c8b30c8d39743b74a7574566f4d`.
The manifest records its coverage gaps and product page.

The radar browse sample is retained for provenance, not applied to the globe:
its cropped extent is not sufficiently specified. Runtime ground color is an
explicit constant ochre approximation, independent of elevation. A separate
procedural haze appearance fades below 70 km to reveal the measured terrain;
this is an inspection aid, not an atmospheric radiative-transfer model.

Reproducibility:

```sh
node scripts/prepare-venus-surface.mjs --download
node scripts/prepare-venus-surface.mjs --rebuild
```

`--rebuild` is offline and verifies both pinned source checksums before
overwriting only the Venus-prefixed derivatives and manifest.
