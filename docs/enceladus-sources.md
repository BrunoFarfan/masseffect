# Enceladus surface preparation

The checked-in Enceladus derivatives are generated by
`scripts/prepare-enceladus-surface.mjs --rebuild` from the ignored original
`output/surface-originals/enceladus-dem.tif`. The source is the USGS
Astrogeology [Enceladus Cassini Global DEM 200m
Schenk](https://astrogeology.usgs.gov/search/map/enceladus-cassini-global-dem-200m-schenk),
published from the Cassini image-based control network and DEM by Schenk and
McKinnon (2024). The pinned GeoTIFF SHA-256 is
`7c08c46238cde6528c9143f0c667d42cd3bc6ac60c572595a7e6cad2d6775f91`.

The GeoTIFF is 8049×4025, north-up, 200 m/pixel, single-band 32-bit float.
Its vertical DN values are kilometres relative to the map's reference shape,
with GDAL NoData `-3.40282265508890445e+38`. There are no GDAL SCALE or OFFSET
items; the source page explicitly defines the vertical units as kilometres,
so the preparation converts valid samples to metres. NoData is not silently
treated as terrain: medium and near height fields fill it with the labeled
reference triaxial ellipsoid (zero relief), and record the valid
sample fraction in the manifest.

## Triaxial datum and runtime height

The source uses the Thomas et al. (2016) triaxial Enceladus shape, not a
sphere: `a=256200 m`, `b=251400 m`, and `c=248600 m`. For each pixel direction,
the script computes the ellipsoid radial intersection
`R=1/sqrt((x/a)^2+(y/b)^2+(z/c)^2)`, then encodes physical radial height as
`R + sourceElevationMeters - 252100 m`. The runtime's canonical body radius is
therefore preserved while the DEM's ellipsoidal datum is respected. The
result is not a normal-to-ellipsoid offset; it is the radial height required
by the spherical runtime renderer. This distinction is explicit because the
source describes elevations relative to the ellipsoidal reference shape.

The source GeoTIFF is east-positive 0..360 with a 180° center longitude and
north-up origin `(-805000, 402600)` m. Preparation performs a metadata-derived
half-raster seam shift to east-positive −180..180; it does not use an
eye-balled flip. The checked-in color is a constant soft-ice fallback because
no mapped Cassini color raster is bundled with this preparation; it is not
presented as real visible color or as a height proxy.

Preview is color-only at 512×256. Medium (1024×512) and near (2048×1024)
contain both color and uint16 little-endian height fields at 0.5 m/sample.
Checksums, dimensions, ranges, source metadata, NoData policy, and provenance
are recorded in `assets/surfaces/enceladus-manifest.json`.
